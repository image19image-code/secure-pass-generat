## ✨ Features | المميزات

* **Clean & Responsive UI:** تصميم عصري ومتجاوب يعمل بسلاسة على جميع الأجهزة والشاشات.
* **Full Customizability:** إمكانية التحكم الكامل في طول كلمة المرور واختيار نوع الأحرف (كبيرة، صغيرة، أرقام، ورموز خاصة).
* **Instant Copy-to-Clipboard:** زر نسخ سريع وفوري بنقرة واحدة مع إشعار بالنجاح.
* **High Security Standard:** توليد عشوائي آمن وقوي للحماية من الاختراقات.
